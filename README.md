# Haskell Dev Container

This container pins the tooling needed for this repository:

| Tool | Version |
| --- | --- |
| Stack resolver | `lts-20.18` |
| GHC | `9.2.7` |
| Cabal | `3.10.3.0` |
| Stack | `2.13.1` |
| Haskell Language Server | `1.10.0.0` |

Open the repository in VS Code, then run **Dev Containers: Reopen in
Container**.  The first build downloads the compiler and language server, so
it takes longer than later rebuilds.
